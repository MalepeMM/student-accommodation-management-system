# Student Accommodation Management System

## Project Description

The Student Accommodation Management System will improve how student accommodation is advertised, managed and communicated.

The current process relies on fragmented channels such as WhatsApp, Facebook, telephone calls, paper records and spreadsheets. This can result in outdated listings, lost information, delayed responses and difficulty tracking applications and maintenance requests.

The proposed system will provide a Flutter application for students, an ASP.NET Core web application for landlords and administrators, and a shared Supabase backend.
